Jeu d’essai

Données fictives livrées avec la suite, pour la découvrir : missions (dont un exercice), pilotes, flotte, disponibilités et affectations de la semaine en cours. À remplacer plus tard par les données de votre compagnie.

Dépôt de données

Adresse HTTPS https://hôte/compte/dépôt.git ou SSH git@hôte:compte/dépôt.git, donnée par votre compagnie. Dépôt privé en HTTPS : identifiant et mot de passe, ou un jeton d’accès en lecture si le compte a la double authentification. En SSH : la clé SSH de cet ordinateur. Les identifiants servent au téléchargement, sur cet ordinateur seulement.

J’ai reçu les données par mail

L’archive .zip du jeu de données (elle contient data_tree.js).

Dépôt git de synchronisation des données (facultatif)

Dépôt distant du dossier data/ : il partage les données entre les postes (bouton « Synchroniser » de l’en-tête). Adresse SSH git@hôte:compte/dépôt.git (clé SSH de cet ordinateur) ou HTTPS https://hôte/compte/dépôt.git (identifiants enregistrés dans Git). Facultatif et jamais bloquant : sans dépôt qui répond, la suite fonctionne, sans partage.

Journal des vols (facultatif)

La page « Log des vols » du site de la compagnie enregistrée (.html) : pilotes et appareils de la référence (aide à la saisie).

2Profil

Repris par toutes les pages (☰ › Profil pilote). Les identifiants du site de la compagnie, le mot de passe et les préférences se règlent ensuite dans Paramètres › Mon profil.

3Dossiers

Le navigateur demande de désigner chaque dossier une fois (il le mémorise).

Dossier de l’application

Le dossier qui contient lancer.cmd et lancer.sh : données, registre, missions, SIA, performances et sauvegarde locale en sont déduits.

Classeur ODV (facultatif)

Le dossier OneDrive (synchronisé) où l’escadrille dépose le classeur : le Planning ODV ouvre le plus récent. Sans OneDrive : choisir le fichier Excel, gardé dans ce navigateur.

4Données aéronautiques et types d’aéronefs

Cartes, missions et planification utilisent les données aéronautiques (AIRAC) et la base des types d’aéronefs. Ci-dessous, les mêmes blocs que dans Paramètres › Installation : choisir les zones (France active par défaut) et, pour chacune, le bouton de chaque source (ZIP du SIA : lien vers la boutique, compte gratuit, produit du cycle à 0 €, puis « Récupérer le ZIP téléchargé » ; MORA ; axes de ravitaillement : PDF MILAIP ; autres pays) — la base se construit seule ; puis « Compléter les types… » pour les types d’aéronefs et leurs performances.
