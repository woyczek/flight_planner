Milan GAAR — plans de vol importables / copiables

Contenu :
- routes_txt/ : champ ROUTE seul, à coller dans SimBrief, IVAO ou VATSIM.
- icao_fpl/ : message FPL ICAO simplifié, prêt à adapter.
- manifest_fpl_routes.csv : index de toutes les missions.

Format utilisé :
- Coordonnées : DDMMNDDDMME, par exemple 4321N00313E.
- Route : DCT coordonnée DCT coordonnée...
- Type avion proposé : DH8D/M.
- Règles de vol : VFR dans les blocs FPL, car ces missions GAAR de simulation utilisent des routes hors réseau ATS.
- Altitude : Axxxxx pour conserver les altitudes de simulation du pack d'origine.

Attention :
Ces fichiers sont faits pour la simulation DEFA Virtual. Ils ne sont pas des plans opérationnels réels.
Ils ne sont pas garantis IFPS/Eurocontrol-validés en IFR, car les routes DCT/coordonnées à basse altitude
peuvent être rejetées par IFPS selon zone, horaire, niveau, restrictions et AIRAC. Pour SimBrief/IVAO/VATSIM,
la route field est normalement le format utile.
