# Documentation — SO Group Virtual suite

*[← Back to the suite](../README.md)*

The documentation is read in the suite itself: **Help** in the sidebar (or ☰ › Help) opens the chapter of the page
you are on. The Help page shows the tutorials first, then the user and administrator manuals (French, English, German,
Spanish), the operations manual and, collapsed, the developer documentation. Its structure is defined once, in
`apps/aide/aide.js` (`HELP`).

- Tutorials: [Install the suite](tutorial/installation.en.md) ([français](tutorial/installation.fr.md))
- Manuals: [User manual](MANUEL_UTILISATEUR.md) · [Administrator manual](MANUEL_ADMINISTRATEUR.md) (French originals;
  translations in `en/`, `de/`, `es/`)
- Operations: [Operations manual](MANUEL_EXPLOITATION.md) · [Installation](INSTALL.md) · [Release notes](VERSION.md) ·
  [Changelog](CHANGELOG.md)
- Developers: [Technical documentation](technique/README.md)
