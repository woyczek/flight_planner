## 3. Dependencies of the references

All the references in [DONNEES.md](../DONNEES.md) have an update process; the “References and
dependencies” table of the Maintenance page checks them on demand: SIA cycle of the folder / of the database / of `mora.csv`,
ENR 5.7 edition, APD performance types present in the ICAO database, DEFA fleet types (aliases
`__aliases` applied: H145 → EC45, A400 → A4M, E2C → E2, RQ9P → Q9), planner profiles, missions prompt
synchronised with `docs/PROMPT_GENERATEUR_MISSIONS.md`, `VERSION.json`.

Finding: 26 of the 35 DEFA fleet types have no EUROCONTROL APD performance data (military types) — expected,
the planner profiles take over; flagged for information.

## 4. Data outside git to protect

`CR DEFA/missions.yaml` (mission report ledger), the historical CSV registries, `Missions/` (generated series),
`flight_performance_database_merged.fpdb.json`, `defa_local_store.yaml` and the JSON mission reports in `CR DEFA/FIRE/`
(including duplicates “(1)”, “(2)”, “(3)”) are ignored by git and protected only by the folder's synchronisation.
The **full backup** (Settings › Maintenance) archives them with the browser data, backed by SHA-256 hashes,
and records each backup and each reload in the log.
