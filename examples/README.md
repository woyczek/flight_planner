# Exemples

Jeux de données minimaux et fictifs, lus par l'application quand le dossier `data/` (clone du dépôt de données)
est absent : `references/` (3 appareils, 1 pilote, 8 indicatifs publics), `missions/Mission 02.md` (mission de
démonstration : ravitaillement en vol sur l'axe SIMONE). Les données réelles sont dans le dépôt de données
(voir INSTALL.md) ; ne pas y ajouter de données personnelles.
