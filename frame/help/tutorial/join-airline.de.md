# Der Fluggesellschaft beitreten

*Zehn Minuten, einmal pro Gerät: von der Konfiguration, die Ihre Fluggesellschaft schickt, zu einem Gerät, das ihre
Daten teilt, mit einem Assistenten, der sich merkt, wo Sie stehen, wenn Sie unterwegs aufhören.*

**Bevor Sie beginnen.** Der Administrator Ihrer Fluggesellschaft schickt Ihnen einen Link, eine sog-config-Datei oder
einen QR-Code, den Sie mit der Kamera Ihres Telefons scannen. Öffnen Sie ihn: der Assistent „Der Fluggesellschaft
beitreten“ startet. Er startet auch von der Willkommenskarte beim ersten Öffnen oder über ⚙ Einstellungen › „Der
Fluggesellschaft beitreten…“.

## 1. Die Konfiguration

![Die erhaltene Konfiguration: Fluggesellschaft, Repository, Kürzel](img/join-airline-1.en.png)

**Prüfen Sie sie.** Die Fluggesellschaft, ihr Daten-Repository und Ihr Kürzel. Sonst wird nichts am Gerät geändert.
Dann „Weiter →“.

## 2. Ihr Konto

![Das Konto anlegen, dann den Benutzernamen](img/join-airline-2.en.png)

**Ein Konto beim Anbieter des Repositorys.** Meist GitHub. Haben Sie schon eines? Wählen Sie „Ja“. Sonst wählen Sie
„Nein, ich erstelle eines“ und folgen den drei Zeilen: registrieren, einen einfachen Benutzernamen wählen, die
E-Mail-Adresse bestätigen. Gehört das Repository Ihrer Fluggesellschaft einem Benutzer, öffnet das Token alle
Repositorys Ihres Kontos: haben Sie schon andere, legen Sie ein eigenes Konto für das Fliegen an.

**Ihr Benutzername.** Tippen Sie ihn ein: der Administrator braucht ihn. Dann „Weiter →“.

## 3. Die Einladung

![Den Namen geben, die Einladung annehmen](img/join-airline-3.en.png)

**Geben Sie Ihren Namen.** „Meinen Namen kopieren“, dann schicken Sie ihn dem Administrator: er lädt Sie in das
Repository ein.

**Nehmen Sie an.** GitHub schreibt Ihnen: öffnen Sie die E-Mail und nehmen Sie die Einladung an (der Link auf dem
Bildschirm führt auch dorthin). Setzen Sie das Häkchen bei „Einladung angenommen“, dann „Weiter →“.

## 4. Das Token

![Das Token auf GitHub erstellen, Schritt für Schritt](img/join-airline-4.en.png)

**Erstellen Sie es auf GitHub.** Folgen Sie den Zeilen: der erste Link öffnet die schon ausgefüllte Seite — ein
„klassisches“ Token mit dem Häkchen „repo“, dem Sie ein Jahr Gültigkeit geben. Gehört das Repository Ihrer
Fluggesellschaft einer Organisation, zeigt der Assistent stattdessen ein feingranulares Token (nur dieses Repository,
„Contents: Read and write“).

**Kopieren Sie es sofort.** GitHub zeigt es nur einmal. Setzen Sie das Häkchen bei „Token kopiert“, dann „Weiter →“.

## 5. Das Token einfügen

![Das getestete Token: Zugang geprüft](img/join-airline-5.en.png)

**Einfügen und testen.** Fügen Sie es ein, dann „Testen“. Ein klarer Satz sagt, was nicht stimmt: Einladung noch nicht
angenommen, Token falsch kopiert oder abgelaufen, oder ohne Recht auf den Inhalt. Einmal geprüft, bleibt das Token nur
auf diesem Gerät. Dann „Weiter →“.

## 6. Ihre Netzkennungen

![IVAO, VATSIM, SimBrief: freiwillig](img/join-airline-6.en.png)

**Freiwillig.** Ihre IVAO-VID, Ihre VATSIM-CID und Ihre SimBrief-Kennung erlauben der App, Ihre Flüge und Ihren letzten
Plan zu übernehmen. Dann „Weiter →“.

## 7. Fertig

![Das Gerät ist eingerichtet und synchronisiert](img/join-airline-7.en.png)

**Schließen Sie ab.** „Abschließen und synchronisieren“ richtet alles ein und macht die erste Synchronisierung. Halten
Sie danach das Gebiet Ihrer Flüge offline bereit („Offline-Daten“), und fahren Sie mit [Einen Flug
vorbereiten](#help?t=prepare-flight) fort.

**Weiterführend.** Das Kapitel Einstellungen des Handbuchs, Abschnitt „Einen Piloten einrichten“
([Einstellungen](#help?m=settings)).
