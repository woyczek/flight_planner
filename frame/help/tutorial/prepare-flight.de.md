# Einen Flug vorbereiten

*Fünf Minuten, in der Reihenfolge der fünf Schritte von Kraftstoff: von einem leeren Bildschirm zu einem auf der Karte
geprüften Flug, mit seinem Kraftstoff, bereit zum Fliegen und zum Berichten.*

**Bevor Sie beginnen.** Nichts ist Pflicht. Ihr Kürzel in ⚙ Einstellungen › Identität lässt den Bericht Sie danach
erkennen; mit einer SimBrief-Kennung kann Kraftstoff auch Ihren letzten Plan auf einmal übernehmen.

## 1. Flug

![Der Schritt Flug: Flugplätze, Luftfahrzeug und Flugfläche](img/prepare-flight-1.en.png)

**Wohin.** Öffnen Sie Kraftstoff über das Menü (☰). Tippen Sie den Abflug, die Ankunft und den Ausweichflugplatz ein,
je vier Buchstaben: LFBO, LFRN, LFRS.

**Womit.** Tippen Sie auf die Lupe und geben Sie Ihr Luftfahrzeug ein: ein Kennzeichen, ein Rufzeichen oder einen Typ,
zum Beispiel TBM9. Wählen Sie es in der Liste. Das Ergebnis erscheint sofort unten im Bildschirm und folgt jeder
Änderung.

**In welcher Höhe.** Tippen Sie eine Flugfläche in „Flugfläche (FL)“, zum Beispiel 280; die beste wählen Sie in
Schritt 4. Dann „Weiter · Route“.

## 2. Route

![Die Karte im Modus Bearbeiten: die Punkte der Route sind umkreist](img/prepare-flight-2.en.png)

**Tippen Sie die Route.** Schreiben Sie in „Route“ die Punkte und Luftstraßen wie in einem Flugplan: LFBO TOU UN460 NTS
LFRN. Verlassen Sie das Feld: die Route wird bereinigt, und die Entfernung erscheint direkt darunter.

**Prüfen Sie sie auf der Karte.** „Karte zeigen“ öffnet Karte auf Ihrem Flug. Tippen Sie auf „Bearbeiten“: ziehen Sie
einen Punkt, um ihn zu verschieben, tippen Sie auf ein Funkfeuer, um es hinzuzufügen, dann „Fertig“. Kraftstoff folgt
jeder Änderung.

**Kehren Sie zurück.** „‹ Kraftstoff“ oben führt zum Schritt Route zurück. Dann „Weiter · Wetter“.

## 3. Wetter

![Der Schritt Wetter: der echte Wind entlang der Route](img/prepare-flight-3.en.png)

**Das Flugplatzwetter.** Online wird es von selbst gelesen: unter dem Wind gibt jeder Flugplatz der Strecke seine
Kategorie, den Wind auf seiner Piste, die Wolkenuntergrenze und die Sicht. „Flugplatzwetter lesen“ liest es erneut.

**Der echte Wind.** Setzen Sie das Häkchen bei „Echtes Wetter: Wind entlang der Route“: die Windfelder übernehmen den
vorhergesagten Wind auf Ihrer Flugfläche.

**Die Temperatur.** „ISA … verwenden“ übernimmt die Temperatur des Tages am Abflugplatz. Dann „Weiter · Ergebnis“.

## 4. Ergebnis

![Die Wahl der Flugfläche: Kraftstoff und Zeit für jede Flugfläche](img/prepare-flight-4.en.png)

**Wählen Sie die Flugfläche.** Die Zeichnung gibt den Kraftstoff (durchgezogen) und die Zeit (gestrichelt) für jede
Flugfläche; der grüne Punkt markiert die sparsamste. Tippen Sie auf „FL… nehmen“, oder tippen Sie auf die Kurve.

**Prüfen Sie die Dienstgipfelhöhe.** Bei großer Hitze oder von einem hoch gelegenen Flugplatz klappen Sie
„Dichtehöhe“ auf: es sagt, in welcher Höhe das Luftfahrzeug an diesem Tag seine Gipfelhöhe erreicht.

**Lesen Sie das Ergebnis.** Die untere Leiste gibt den Blockkraftstoff, den Streckenkraftstoff, die Flugzeit und den
Sinkflugbeginn. Dann „Weiter · Abflug“.

## 5. Abflug

![Der Schritt Abflug: die Zusammenfassung und „Flug starten“](img/prepare-flight-5.en.png)

**Prüfen Sie die Zusammenfassung.** Luftfahrzeug, Route, Flugfläche, Wind und Blockkraftstoff, auf einer Karte.

**Starten Sie den Flug.** „Flug starten“ öffnet die Karte auf Ihrem Flug und bewahrt ihn für den Bericht. Nach der
Landung folgen Sie [Einen Bericht schreiben](#help?t=write-report).

**Weiterführend.** Wie jeder Schritt funktioniert: die Kapitel [Kraftstoff](#help?m=fuel) und [Karte](#help?m=maps)
des Handbuchs.
